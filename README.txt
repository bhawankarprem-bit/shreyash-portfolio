SHREYASH BHAWANKAR — CREATIVE JAVA DEVELOPER PORTFOLIO
=====================================================

CONTENTS
- index.html : Main portfolio page
- style.css  : Creative responsive design and animations/visual styling
- script.js  : Mobile navigation and active section highlighting
- assets/    : Place your profile photo and resume here if you want to add them

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html (or right-click > Open with > Chrome / Edge).
4. Internet is required for the Google Fonts; the site itself works without them using fallback fonts.

PUBLISH FOR FREE
Option A — GitHub Pages:
1. Create a GitHub repository for the portfolio.
2. Upload index.html, style.css, script.js and assets folder.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select main branch and /(root), then Save.
5. GitHub will provide your live website URL.

Option B — Netlify:
1. Open Netlify and sign in.
2. Choose Add new site / Deploy manually.
3. Drag the extracted portfolio folder into the deploy area.
4. Netlify will publish a live URL.
